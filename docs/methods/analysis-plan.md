# 整体分析计划

> 状态：已冻结，等待全量数据实现

## 证据阶梯

### 1. 覆盖审计

- 通知记录、撤稿论文和作者关系分层计数。
- 中国大陆候选、OpenAlex 确认和机构完整三个样本量。
- DOI、机构、国家、学科、来源、资助字段覆盖。
- 匹配前后协变量平衡。

### 2. 原因族描述

- 原因族规模与年度趋势。
- 原因标签共现。
- 2023 年批次构成。
- 原论文发表年份与撤稿时滞。

### 3. 论文层比较

- 团队机构层级。
- 合作地理层级和距离。
- 团队人数。
- 三主原因族分别对比匹配非撤稿论文。

### 4. 网络与社群

- 作者合作网络。
- 跨论文重复合作。
- 跨层级、跨省和跨国边。
- 置换零模型与社群稳定性。

### 5. 2023 事件

- 撤稿月份和批次时间线。
- 出版社、期刊和原论文发表年构成。
- Crossref 期刊年度分母。
- 外部公开资料机制证据。

### 6. 资助审计

- 25 个待核查社群。
- 最多约 500 篇论文。
- 资助机构与项目编号组合。
- 官方金额附录。

## 方法分工

| 方法 | 回答 | 不承担 |
|---|---|---|
| 描述统计 | 样本是什么 | 原因净效应 |
| 匹配混合模型 | 结构是否不同 | 因果识别 |
| 网络零模型 | 是否超过构成基线 | 个人责任 |
| Leiden 社群 | 哪些作者形成结构群 | 组织定性 |
| 条件 logistic | 方向是否稳健 | 替代主模型 |
| 事件拆解 | 2023 峰值怎样形成 | 国家不端率 |
| 资助审计 | 资源组合是否重叠 | 造假动机 |

## 多重比较与报告

- 三个主原因族的同类结果统一做 Benjamini-Hochberg FDR。
- 报告效应量、置信区间和样本量。
- p 值不能替代方向、量级和稳健性。
- 计划结果与已完成结果分开标记。

## 输出顺序

所有分析先输出审计表和机器可读结果，再生成正文图。报告和 Shiny 只读取冻结输出。
