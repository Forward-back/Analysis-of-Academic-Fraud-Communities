# 网络与社群方法

> 状态：已冻结；P2 网络、零模型和 25 个审计簇已实现

## 网络构建

- 节点：OpenAlex 作者 ID。
- 边：两位作者共同署名同一篇撤稿论文。
- 同一论文内作者去重。
- 主网络使用无权边。
- 团队规模归一化权重只作敏感性分析。
- 跨机构、跨层级、跨省和跨国边分别标记。

## 网络指标

- 节点数、边数、组件数。
- 最大组件占比与组件规模分布。
- 密度、聚类和度集中。
- 跨机构、跨层级和跨地理边比例。
- 跨年持续结构。
- 重复合作作者对比例。

不同原因族全图指标必须结合样本量和团队构成解释。

## 零模型

随机重连或重抽样保持：

- 论文团队规模。
- 年份。
- 学科。
- 出版社。
- 样本论文数。

目标是比较观察边结构是否超过团队构成所预期的水平。至少 1,000 次置换，固定种子并保存分布摘要。

当前实现采用“撤稿年份 × 学科 `field` × 出版社”分层。每篇论文保持团队人数，
层内作者不放回抽取，选择概率与该作者在原层内的出现次数成比例。该模型不保持
作者度，需用作者度保持配置模型作敏感性检查。

作者度保持敏感性采用随机端点配对：保留作者加权共同作者度、边出现次数和节点集合，
随机重配共作者端点，排除自环。该模型不保留论文团队、年份、学科和出版社结构，
只用于检验重复边是否超过仅由度序列解释的水平。

社群候选采用重复合作网络的连通组件，而不是把碎片化 Leiden 分区直接当作社群。
固定 25 个审计簇前加入 2023 份额和排除 2023 稳定性保护，选择规则见
[ADR 0010](../decisions/0010-audit-cluster-selection.md)。

## 主信号

**跨论文重复合作超额**

同一作者对至少共同出现于两篇撤稿论文，记为重复合作边。主筛选使用该指标相对零模型的超额，不以最大组件规模为主。

## 社群检测

- 使用 Leiden。
- 分辨率参数扫描。
- 固定种子。
- 社群在分辨率变化、年份切片和抽样扰动中保持一定的稳定性。
- 至少 5 篇论文。
- 至少跨 2 个年份。

## 待核查社群筛选

1. 计算重复合作超额和稳定性。
2. 固定选取 25 个社群。
3. 不根据资助是否易查、作者姓名或媒体关注人工增删。
4. 社群编号稳定，不展示个人排行榜。

## 稳健性

- 无权重与团队规模归一化。
- 作者 ID 网络与姓名加机构审计网络。
- 包含和剔除前五大批次。
- 剔除与对照共享作者的论文。
- 社群检测算法与分辨率变化。
