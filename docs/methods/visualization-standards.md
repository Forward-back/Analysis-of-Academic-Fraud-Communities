# 学术审计图可视化规范

> 状态：已对齐，版本 `1.0`
> 适用范围：分析审计图、报告图、演示图和 Shiny 图
> 对齐日期：2026-11-21

## 目标

图表只承担五类任务：展示覆盖、比较差异、检查复用、定位时间和说明边界。图形必须
优先帮助读者判断分母、缺失和不确定性，不使用装饰性元素替代证据。

所有最终图由脚本读取冻结表生成，不手工修改图形数值。报告、演示和 Shiny 使用同一
派生数据，不在页面代码中重新计算统计量。

## 配色

项目保留 B、C 两套莫兰迪配色。选择依据是图形的首要问题，不是页面主题或个人偏好。
用户建议配色的场景审查与取舍见[建议配色审查](palette-review.md)。

### B：组间比较

B 用于审计样本与非撤稿对照、未入选候选簇、原因族或模型规格之间的差异比较。

| 语义 | 色值 |
|---|---|
| 主比较组 | `#2F8F9D` |
| 对照或第二组 | `#D96C62` |
| 第三组 | `#86B86E` |
| 重点数量 | `#EDB75C` |
| 不确定或次要 | `#9580B3` |
| 中性标记、零线 | `#7D898D` |
| 缺失、无记录 | `#D6D2CB` |
| 正文文字 | `#24343A` |
| 背景 | `#FBFAF7` |

### C：时间、批次和核验状态

C 用于月度趋势、同日批次、事件时间线、来源类型和官方核验状态。

| 语义 | 色值 |
|---|---|
| 主过程或已核验 | `#6FA35B` |
| 第二过程或未核验 | `#DE765B` |
| 时间辅助线 | `#479DB5` |
| 事件重点 | `#EDB45F` |
| 不确定或次要 | `#9B86AA` |
| 中性标记、零线 | `#7D8983` |
| 缺失、无记录 | `#D6D2CB` |
| 正文文字 | `#253432` |
| 背景 | `#FBFAF7` |

### 选择规则

1. 首要问题是“组和组是否不同”时使用 B。
2. 首要问题是“何时发生、属于哪个批次、证据核验到哪一步”时使用 C。
3. 一个图形只使用一个主调色板。图中最多使用 4 个色相，其余类别转为中性灰、
   形状或分面。
4. 同一图形系列固定配色和语义，不因结果方向、显著性大小或版面位置换色。
5. 同时包含组和时间时，由首要问题决定主调色板；次要变量使用形状、线型或分面，
   不以增加色相解决。
6. 二分类固定为主组和对照组；三组以上优先“主组、对照、灰”，必要时才加第三色。
7. 缺失使用灰色加斜线或空心标记，不使用白色、零值位置或“0”标签。
8. 发散差异图只使用陶土、雾青和中性灰表示负、正、零，并在点旁直接标方向和数值。
9. 颜色不能是唯一编码。数据序列同时使用形状、线型、直接标签或分面。
10. 不使用高饱和红绿对立表示显著和不显著。显著性与不确定性通过区间、标记和文字
    表达。

### 补充色板

- 连续热图：Viridis。
- 围绕零点的有符号矩阵：RdBu_r，零固定在中性色并要求对称范围。
- 二元正负：暖冷双色对，正值固定蓝、负值固定珊瑚，并保留零线。
- 单一重点：灰色基线加一个强调色。
- 色盲安全备用：Okabe-Ito，同时使用形状和深色边框。
- 分类分组：Tableau 10 最多取前 4 个色相，完整 10 色不作为颜色唯一编码。
- 时间多线：Bloomberg 风最多 3 条序列，配合形状和直接标签。
- 探索性分类散点：Tab10 soft 最多 4 类并配合分面或形状。
- Morandi 低饱和不作主比较色板；仅在明确要求低对比报告风格时使用。

## 字体与线条

- 拉丁字母、数字和英文单词使用 `Arial`。
- 中文使用黑体；优先 `SimHei`，渲染回退不得使用宋体、楷体或其他衬线字体。
- 混合中英文文本由字体族回退处理。纯英文标题、坐标和图例使用 `Arial`；纯中文
  标题和说明使用黑体。
- 图题：`10.5 pt`，粗体。
- 副标题、轴标题和图注：`8.5 pt`。
- 轴文字和直接标签：`8 pt`。
- 正文色使用 B 的 `#24343A` 或 C 的 `#253432`，不把浅灰用于需要阅读的文字。
- 图题置于图形顶部中央；副标题同样居中，图注保持左对齐。
- 主数据线：`1.2 pt`；对照线：`0.9 pt`；坐标轴：`0.6 pt`；网格：`0.3 pt`。
- 同一系列的点、线和区间使用固定尺寸，不用尺寸暗示统计显著性。
- 图形导出后不缩放字体来适配容器。移动端通过重排、缩短标签或减少直接注释解决。

## 图形选择

- 覆盖率和单一分组数量：水平条形图或点图，附分母和 95% 区间。
- 两个相关组的差距：点线图、哑铃图或森林图；不使用双纵轴。
- 多个模型规格：森林图或小多图，零线固定为 `1` 或 `0`，按指标含义决定。
- 时间变化：折线、阶梯线或事件时间线；事件注释只保留解释所需节点。
- 同日批次和核验状态：时间线、点图或状态条带；同一天多个事件按语义分组。
- 复用关系：矩阵或分面点图；同时提供带精确计数的表后备。
- 分布：小多图、箱线或分位数图；不使用装饰性密度叠加。
- 热力图只使用单色顺序色阶，并直接标出关键计数。

禁止使用饼图、环图、3D 图、双纵轴、截断零基线的条形图、未经说明的对数轴和以面积
暗示因果关系的装饰图。

## 注释和证据

每张图必须有：

1. 中文标题，文件名使用英文和稳定图形编号。
2. 一句说明图形问题或口径的副标题。
3. 每个数据组的样本量或分母。
4. 缺失数量、缺失定义和是否使用完整案例。
5. 数据来源和冻结版本。
6. 95% 区间、模型不确定性或明确说明为何未绘制。
7. 表后备文件，提供图中使用的全部数值。
8. 生成脚本、数据哈希、图形哈希、访问日期和替代文本。

图注不得只写“如图所示”。图注至少说明图形问题、分母、来源、缺失口径和一个解释
边界。若图来自资助、网络或审计簇分析，必须保留相应限制：

- 无资助记录不等于无资助。
- 项目编号重复不等于不端。
- 审计簇不是责任主体，也不能转换为个人或社群风险分数。
- 网络完整样本不能外推为全样本。
- 2023 年峰值不能直接解释为国家不端率变化。

## 尺寸和导出

- 报告正文图宽：`160-170 mm`。
- 单栏报告高度：`70-95 mm`；复杂图不超过 `135 mm`。
- 桌面预览：宽 `1600 px`。
- 手机预览：宽 `800 px`，优先纵向重排，不缩小到不可读。
- 矢量输出：`SVG` 和 `PDF`。
- 位图预览：`PNG`，桌面和手机各一档。
- 所有导出保留相同图形内容；移动端可以调整图例、分面和标签位置，但不改变数值。

## 文件契约

图形编号使用 `<phase>_<topic>_<chart_type>`，例如
`p4_funding_coverage_dotplot`。每个最终图至少生成：

- `data/outputs/<phase>/figures/<figure_id>.svg`
- `data/outputs/<phase>/figures/<figure_id>.pdf`
- `data/outputs/<phase>/figures/<figure_id>_desktop.png`
- `data/outputs/<phase>/figures/<figure_id>_mobile.png`
- `data/outputs/<phase>/tables/<figure_id>_data.csv`
- `data/outputs/<phase>/figures/<figure_id>_metadata.json`

元数据记录：图形问题、分母、来源表、缺失规则、生成脚本、访问日期、替代文本、表
后备路径、数据哈希和图形哈希。SVG、PDF、PNG 使用逐字节哈希；CSV 和 JSON 使用
项目现有的规范化文本哈希。

测试图放在 `data/outputs/audits/figures/`，文件名以 `style_test_` 开头，不进入最终
报告目录，避免未审核图被下游误用。

## 可访问性检查

- 正文文字与其背景对比度不低于 `4.5:1`；数据标记与背景不低于 `3:1`。
- 使用红绿色盲、蓝黄色盲和灰度模拟检查区分度。
- 不用颜色表示排名高低或价值判断。
- 每个交互图有等价静态图或表。
- 每个图有简短替代文本；替代文本只描述可观察内容，不替读者下因果结论。
- 手机预览中文字不重叠、不截断、不遮挡数据。

## 审查门槛

图形进入报告或 Shiny 前必须通过：

1. 问题与图形类型匹配。
2. 调色板符合 B、C 选择规则。
3. 分母、缺失、区间和来源完整。
4. 坐标轴、零线和尺度没有被误导性截断。
5. 黑白打印和两类色盲模拟仍可读。
6. 桌面和手机预览无文字溢出或重叠。
7. 图数据、表后备和脚本可复现图中的数值。
8. 解释符合研究边界，不生成个人、机构或社群责任排序。
