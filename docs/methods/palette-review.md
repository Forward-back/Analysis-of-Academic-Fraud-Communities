## 正式色板

项目仅使用以下色板：

| 色板 | 用途 | 规则 |
|---|---|---|
| B | 组间比较 | 主组、对照、第三组、重点和缺失的固定语义 |
| C | 时间、批次和核验状态 | 主过程、未核验、时间辅助、事件重点和缺失 |
| Viridis | 连续热图 | 只表示连续值，不使用于无序分类 |
| RdBu_r | 有符号差异 | 零固定为中性白，范围围绕零对称 |
| Okabe-Ito | 色盲安全备用 | 用于投稿和无障碍复核，必须配合形状和深色边框 |

强调图不增加第六套色板：基线使用中性灰，重点使用 B 或 C 的强调色。

## 已移除方案

以下方案完成过场景测试，但不进入正式规范：

- Tableau 10：完整分类数过多，色盲模拟下的部分颜色组合区分不足。
- Bloomberg 风：多线颜色接近，正式图继续使用 C 加形状和直接标签。
- Tab10 soft：完整色组不稳定，分类散点继续使用 B/C。
- 冷暖双色对：与 RdBu_r 功能重复，正式有符号图统一使用 RdBu_r。
- Morandi 低饱和：明度和色差不足，不再用于主比较。

历史测试图和逐色指标保留在 `data/outputs/audits/`，用于复核取舍，不作为推荐菜单。

## 强制规则

- 新图不得直接引用 `config/visualization-review.yml`。
- 一个图形只使用一套主色板，分类最多 4 个色相。
- 颜色不是唯一编码；形状、线型、分面和直接标签至少再用一种。
- 连续热图使用 Viridis；正负矩阵使用 RdBu_r。
- 缺失使用灰色加斜线或空心标记，不放在零值颜色位置。
- 饼图、3D、双纵轴和截断零基线的条形图仍禁止。
