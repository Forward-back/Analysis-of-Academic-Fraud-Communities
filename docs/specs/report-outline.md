# 综合报告提纲

> 状态：计划

1. 引言：出版社为什么需要区分撤稿原因与核查能力。
2. 文献与理论：撤稿原因、论文工厂、合作网络和学术治理。
3. 数据来源：Retraction Watch、OpenAlex、Crossref、ROR 与公开名单。
4. 数据清洗与中国大陆样本：三个计数层级和覆盖审计。
5. 原因族构造：多标签映射、重叠和探索性族。
6. 研究设计：匹配非撤稿论文、结果变量与方法。
7. 资源位势结构：机构层级、地理与团队规模。
8. 网络与待核查社群：重复合作超额和稳定性。
9. 2023 年批量撤稿事件：本地构成、期刊分母和公开资料。
10. 资助组合专项：覆盖、共享项目和官方金额证据。
11. 稳健性、限制与伦理。
12. 管理建议与结论。
13. 附录：变量、映射、检索、AI 使用和复现。

## 写作原则

- 每节先问题，再数据，再结果，再解释。
- 每张表有样本量和口径。
- 不把计划写成结果。
- 管理建议逐条对应结果。
