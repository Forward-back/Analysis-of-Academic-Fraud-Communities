# 质量门槛

> 状态：已冻结

## 数据

- DOI 精确匹配低于 75%：作者网络降级。
- DOI 匹配 60% 至 75%：主结论写为探索性。
- 机构完整子集低于 70%：机构层级与地理结论降级。
- 原因族低于 1,000 DOI：不作等权主推断。
- 宽定义族只作敏感性分析，不能替代窄定义主结果。
- `unclassified` 不是原因族，不进行族间效应解释。
- 资助元数据低于 50%：只放附录或专项。

## 匹配

- 每篇撤稿论文实际对照数 0、1、2 分别报告。
- 0、1、2 以全部中国大陆主分析论文为分母；无匹配层与匹配后未获得对照分别审计，并共同计入 0 篇对照。
- 精确层、学科退化和出版社退化的比例报告。
- 匹配前后年份、学科、来源和作者规模平衡检查。
- 对照作者重叠比例报告。

## 模型

- 收敛状态、奇异拟合和随机效应方差必须报告。
- 所有效应量附区间。
- 三个主原因族的同类比较做 FDR。
- 次级文本复用、作者身份和探索族分别报告样本量与比较族。
- 主模型与稳健性方向冲突时，不作强结论。

## 社群

- 固定 25 个，不以结果或媒体关注人工增删。
- 社群规模、年份跨度、重复合作超额和稳定性全部报告。
- 最大组件不能单独作为待核查理由。

## 交付

- 每个报告数字定位到输出文件。
- Markdown 链接有效。
- Shiny 空状态、筛选和下载可用。
- 个人、机构或出版社责任表述通过伦理检查。

## 仓库契约

- `data/external/` 不出现项目脚本生成的映射。
- `data/reference/` 的修改通过新版本完成，不覆盖旧版本。
- `data/outputs/` 使用阶段优先结构，阶段内部使用 `tables/`、`figures/` 和 `models/`。
- manifest 不含绝对路径、用户名、临时目录、邮箱或 API key。
- 文本 manifest 与 provenance 使用 LF 规范化内容哈希；原始和二进制文件使用逐字节哈希。
- 大型 RDS、原始 CSV 和 API 缓存不进入 Git。
- 应用和报告发布前运行 `scripts/build_deliverables.R`。
- PR 使用统一模板，并报告研究口径、目录边界和构建方式是否发生变化。
