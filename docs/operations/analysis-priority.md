# 后续挖掘与分析优先级

> 状态：当前执行顺序
> 建立日期：2026-11-21
> 依据：研究定位、范围与假设、整体分析计划、当前状态、匹配与网络审计

## 排序原则

后续工作按“先保证样本和口径可信，再生成推断结果，最后扩展解释和交付”的顺序推进。
排序依据是错误一项结论会污染多少下游结果，而不是任务是否容易完成或图表是否醒目。

1. 先审计分析样本、缺失和选择偏差。
2. 先完成证据链最靠近主假设的论文层分析。
3. 网络结果必须建立在网络样本选择审计之上。
4. 2023 事件外部证据可以独立推进，但不能替代主样本审计。
5. 资助审计受覆盖率限制，放在结构分析之后。
6. 报告、图表和 Shiny 只消费冻结输出。

不得为了绕开 OpenAlex 限流而对机构地理字段插补，也不得把完整子集结果外推为全部
24,974 篇论文的结论。

## 执行顺序

### P0：冻结分析样本并审计选择偏差

这是当前关键路径。没有模型样本冻结，不进入主模型。

状态：已完成（2026-11-21）。结果见
[分析样本冻结与选择审计](../analysis/analysis-samples.md)。

1. 建立论文匹配组审计表，逐案例记录原因族、匹配层、对照数、团队人数、
   对照作者完整性、对照机构完整性、共享作者和出版社批次。
2. 比较 2,776 篇零对照案例与有对照案例在原因族、年份、出版社、来源层和团队规模上的差异。
3. 比较 3,767 个缺失机构影响的案例与完整案例，确认缺失是否集中在特定原因族、
   匹配层、年份或出版社。
4. 冻结全样本、机构完整子集和可用于匹配比较的子集；每个口径标明分母和分析范围。
5. 审计网络完整的 14,827 篇论文相对其余 10,147 篇大陆主分析论文的选择差异。
6. 所有缺失采用显式分层、完整案例限制或标记，不插补机构身份和地理位置。

阶段输出：

- 论文层模型样本审计表。
- 机构与对照完整性分层表。
- 网络样本纳入与排除比较表。
- 冻结样本规则和模型分母说明。

完成门槛：

- 每个主分析结果都能明确说明使用哪个样本。
- 零对照、机构缺失和网络不完整不再只以脚注计数出现。
- 主要缺失模式已按原因族、年份、出版社和匹配层量化。

重点观察：

- 缺失是否与原因族或出版批次强相关。
- 零对照案例是否集中于少数期刊年度层。
- 网络完整子集是否系统偏向较新、较大或特定出版社的论文。

### P1：论文层描述与主推断

样本冻结后先做描述，再做模型。描述结果先回答“样本是什么”，模型只回答调整后的结构关联。

状态：P1A 描述、P1B 核心调整模型和 P1C 稳健性已完成（2026-11-21）。

P1A 结果见 [论文层原因族描述](../analysis/paper-descriptives.md)，
P1B 结果见 [论文层调整模型](../analysis/paper-models.md)，
P1C 结果见 [论文层模型稳健性](../analysis/paper-model-robustness.md)。

1. 按三个主原因族描述机构层级、合作地理、团队人数和年份分布。
2. 将每个原因族与其匹配非撤稿论文比较，单独报告匹配覆盖和选择差异。
3. 建立 `cross_tier`、`domestic_cross_province`、`international`、团队人数和距离结果模型。
4. 分别检验 H1 与 H2；多标签论文允许进入多个族，不构造互斥主因。
5. 对团队规模、机构缺失、主机构口径、作者重叠、固定层级名单和剔除 2023 批次做敏感性分析。
6. 三个主原因族同类结果统一做 BH FDR，并保留效应量、区间、样本量和收敛诊断。

阶段输出：

- 原因族描述表与图。
- 匹配基线与未匹配样本比较表。
- 论文层主模型和敏感性模型结果。
- H1、H2 的证据状态。

完成门槛：

- 机构与地理结果只来自相应完整子集。
- 团队规模差异被控制或明确分层。
- 模型失败和不收敛有记录，不通过隐藏调参制造结果。

### P2：网络层比较与审计簇画像

现有零模型证明重复合作超过若干随机基线，但尚未充分回答原因族间是否存在可比较的超额。

状态：已完成（2026-11-21）。结果见
[网络原因族条件比较](../analysis/network-conditioned.md) 和
[25 个待核查审计簇画像](../analysis/audit-cluster-profiles.md)。

1. 完成网络完整率选择审计。
2. 在保持团队规模、年份、学科、出版社和样本量后，比较原因族重复合作超额。
3. 区分绝对超额、标准化超额和跨年重复，避免把不同量纲直接排名。
4. 描述重复边的机构层级、同城、同省、跨省和跨国构成。
5. 对 25 个审计簇补充年份、出版社、期刊、原因族、团队规模和 2023 批次画像。
6. 检验审计簇排序对边定义、年份剔除和社群稳定性的敏感性。

阶段输出：

- 网络样本选择比较表。
- 原因族条件比较表。
- 重复边地理与层级构成表。
- 25 个审计簇完整画像。
- H3 的证据状态。

完成门槛：

- 不把两套零模型的效应量或 `z` 值直接横向比较。
- 不把审计簇写成责任判断或高风险社群。
- 网络结论明确标注 59.36% 覆盖率及其选择风险。

### P3：2023 外部治理证据

本阶段可早于 P1、P2 独立推进，因为主要依赖公开治理资料，不受 OpenAlex 机构限流影响。

状态：已完成（2026-11-21）。结果见
[2023 外部治理证据](../analysis/event-2023-external.md)。

1. 为出版社公告、期刊处理记录和第三方调查建立来源表，记录 URL、发布日期、访问日期和原文摘录。
2. 将外部事件日期与同日批次、期刊、原论文年份和原因族时间线对应。
3. 区分出版社清理行动、同行评审问题、图像问题和研究伦理标签，避免一个标签覆盖全部机制。
4. 明确无法由公开资料支持的部分，形成反事实边界。

阶段输出：

- 2023 外部治理事件证据表。
- 事件时间线与本地批次对照。
- H4 的证据状态和未解决边界。

完成门槛：

- 每个外部事实有可定位来源和日期。
- 不使用通知峰值推导国家不端率。
- 外部资料与本地统计冲突时保留冲突，不强行拼接。

### P4：资助可追溯性审计

状态：P4A 样本冻结与来源覆盖已完成（2026-11-21），P4B 官方项目记录核验待执行。
结果见 [资助可追溯性审计](../analysis/funding-audit.md)。

1. 从 25 个审计簇中先冻结最多约 500 篇论文的抽样清单。
2. 报告资助机构、项目编号覆盖率、资助机构多样性和项目编号复用。
3. 只有官方可核验金额进入附录，缺失不补零、不插补、不分摊。
4. 与匹配非撤稿基线和未入选撤稿结构比较。

阶段输出：

- 冻结抽样清单。
- 资助覆盖与组合指标。
- H5 的证据状态。

完成门槛：

- 有记录覆盖低于 50% 时只进入附录或专项，不作主结论。
- 不把资助金额解释为动机或风险分数。

### P5：结果整合与交付

1. 冻结主结果表、模型对象摘要和报告图。
2. 每个正文数字定位到 `data/outputs/`。
3. 报告、汇报和 Shiny 共用同一派生数据源。
4. 执行单元测试、集成测试、manifest、链接、敏感信息和复跑检查。

## 阶段完成协议

每完成一个阶段：

1. 保存可复核输出和最小必要日志。
2. 更新对应分析文档、当前状态和进度日志。
3. 运行与改动风险相称的测试或链接检查。
4. 在 `codex/analysis-exploration-plan` 分支提交并推送到 GitHub。
5. 用简短消息同步阶段结论、惊奇发现和解释边界。

## 惊奇发现和边界同步规则

以下情况立即记录到
[探索发现与边界日志](../progress/exploration-findings.md) 并同步：

- 结果方向与研究假设相反或明显超出预期。
- 缺失、零对照或网络排除集中于特定原因族、年份或出版社。
- 两套方法给出方向冲突。
- 一个结果主要来自某个批次、期刊或少数审计簇。
- 外部证据与本地时间线冲突。
- 某条结论无法使用当前样本回答。

同步时分开写“观察”“证据”“边界”“下一步”，不把待核查线索写成既定结论。
