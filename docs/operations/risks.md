# 风险登记

| 风险 | 预警 | 处理 |
|---|---|---|
| OpenAlex 额度不足 | 429 或预算耗尽 | 分批缓存、固定种子、断点续抓 |
| 国家口径不一致 | OpenAlex `CN` 确认明显低于候选 | 保留候选/确认分层，不用姓名补造 |
| 作者 ID 冲突 | 同名高频、ORCID 多 ID | 标记冲突、人工抽查高影响节点 |
| 机构映射不足 | 机构 ID 或省市缺失偏高 | 完整子集主分析，部分缺失敏感性 |
| 2023 批次支配 | 年度趋势与单一出版社高度重合 | 全样本与剔除批次并列报告 |
| 原因族重叠 | 组间差异随窄定义消失 | 多标签、窄定义和共现报告 |
| 模型不收敛 | 随机效应奇异或 Hessian 失败 | 简化模型、稳健标准误、记录原因 |
| 资助覆盖低 | 有记录比例低于 50% | 只作附录和第二期专项 |
| 全文许可限制 | 大量付费墙 | 只用公开元数据和官方项目页面 |
| 时间不足 | 核心结果未冻结 | 削减展示层，不削减审计和口径 |
