# 0010：重复合作组件作为待核查审计簇

- 状态：已接受
- 日期：2026-11-19
- 决策范围：Leiden 敏感性、候选簇构造、25 个固定审计簇

## 背景

完整合作网络和重复合作网络都高度碎片化。完整网络的 Leiden 模块度约
`0.997`；重复合作网络在 `0.5–2.0` 分辨率下给出完全相同分区，VI 为 0。
把这些结果称为“Leiden 社群”会夸大分层能力。

## 决策

- 主候选单位改为 `paper_count >= 2` 重复合作网络的连通组件。
- Leiden 只用于敏感性检查，不用于主候选编号。
- 候选至少包含 5 篇有至少两名成员的论文，且跨至少 2 年。
- 2023 论文占比不得超过 50%，排除 2023 后组件稳定性不得低于 0.5。
- 合格候选按多年度重复边、内部重复边、论文数、年份跨度和 bootstrap 稳定性排序。
- 固定选择 25 个，编号完成后不再按资助、媒体或人工印象调整。

## 后果

- 候选是重复合作审计簇，不是作者风险标签或正式学术不端社群。
- 2023 批次不能单独驱动主候选清单。
- Leiden 仍作为敏感性证据报告；若后续网络构造变化，需重新审计组件质量。
