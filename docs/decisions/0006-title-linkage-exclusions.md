# 0006：精确 DOI 中的标题冲突排除

- 状态：已接受并冻结
- 日期：2026-11-18
- 决策范围：OpenAlex 精确 DOI 返回作品的标题一致性
- 用户确认：是

## 背景

OpenAlex 全量解析后，大陆确认样本中有 4 篇作品虽然 DOI 精确匹配，
但 OpenAlex 标题与 Retraction Watch 原论文标题严重不一致。
候选标题词覆盖均低于 `0.2`，OpenAlex 作品实际为撤稿通知、错误论文或其他记录。

## 排除清单

| DOI | OpenAlex 返回标题问题 |
|---|---|
| `10.1093/carcin/bgt276` | `Notice of Retraction`，未返回原论文 |
| `10.1093/carcin/bgr033` | `Notice of Retraction`，未返回原论文 |
| `10.1016/j.biocel.2007.05.023` | 指向另一篇 siRNA 肝细胞癌论文 |
| `10.1145/3292425.3292445` | 指向另一篇神经网络论文 |

## 决策

- 该 4 篇从大陆主分析、机构完整样本和网络完整样本排除。
- 保留原始记录、OpenAlex 响应、标题审计和排除状态。
- 不使用题名、PubMed ID 或人工猜测补配其他作品。
- 其余 33 篇 Jaccard `<0.5` 的精确 DOI 作品保留。
- 保留理由包括撤稿前缀、通知标题、化学式连字符和翻译题名；
  这些差异不构成足以排除的严重冲突。

## 影响

- 论文层主样本以 24,974 为起点。
- 机构与地理主分析使用 21,842 篇机构完整样本。
- 作者 ID 网络使用 14,827 篇网络完整样本。
- 标题冲突排除属于数据链接质量校正，不解释为论文质量或作者责任。
