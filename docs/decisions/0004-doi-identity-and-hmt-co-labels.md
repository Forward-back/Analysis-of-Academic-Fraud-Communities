# 0004：DOI 论文身份与港澳台共标签

- 状态：已接受
- 日期：2026-11-18
- 决策范围：DOI 折叠、歧义 DOI、通知合并与港澳台候选标记

## 背景

核心窗口内的 49,453 条有效 DOI Retraction 记录折叠为 49,294 个 DOI。
复核发现，DOI 不能在所有情况下直接作为唯一论文键：

- `10.1080/02699052.2023.2194723` 对应 145 条记录和 145 个不同题名。
- `10.1136/jim-2021-srmc` 对应 6 条记录和 6 个不同题名。
- `10.3109/02699052.2016.1162060` 对应 2 条记录和 2 个不同题名。
- 另有 9 组 DOI 的多条通知指向同一标准化题名。

中国大陆候选记录中同时存在 `China` 与 `Hong Kong`、`Macau` 或 `Taiwan`
标签的情况，因此国家候选字段也不能直接决定机构地理边界。

## DOI 决策

### 描述性论文面板

- 论文身份键使用“规范化 DOI + 规范化题名”。
- 同一身份的多个通知合并：保留全部 `Record ID`，原因取并集，
  撤稿日期保存最早和最后日期。
- 歧义 DOI 下的不同题名分别保留，用于描述性审计。

### 可链接主面板

- DOI 仅对应一个规范化题名时，方可标记为 `linkable`。
- 歧义 DOI 全部标记为 `ambiguous_doi`，保留审计记录，
  不进入 OpenAlex DOI 匹配、非撤稿匹配和主模型。
- 不使用题名、作者姓名或国家标签替代歧义 DOI 的 OpenAlex 连接。
- 如后续引入 PubMed ID 或其他稳定作品标识，须另建版本和 ADR，
  不得静默改变本版主面板。

## 港澳台共标签

- 港澳台国家标签单独识别并保留 `country_candidate_hmt`。
- 一篇论文同时存在 `China` 和港澳台标签时，可进入候选池，
  但保留 `country_hmt_labels` 供最终 OpenAlex 机构核验。
- 主样本最终要求至少一个 OpenAlex 机构国家代码为 `CN`。
- 仅有 `HK`、`MO` 或 `TW` 机构的论文不并入中国大陆主样本。
- 大陆机构和港澳台机构同时出现时，港澳台机构单列，
  不计入普通境内省级地理层级。

## 当前结果

| 指标 | 数量 |
|---|---:|
| 核心有效 DOI 通知记录 | 49,453 |
| 唯一有效 DOI | 49,294 |
| 描述性论文 | 49,444 |
| DOI 唯一且可链接论文 | 49,291 |
| 歧义 DOI 组 | 3 |
| 歧义 DOI 记录 | 153 |
| 同题重复通知额外折叠 | 9 |
| 中国大陆候选唯一 DOI | 26,526 |
| 候选含港澳台共标签 | 172 |

三个歧义 DOI 均未进入中国大陆候选，因此候选总数仍为 26,526。

## 影响

- 基线 EDA 的记录数不能直接等同于论文数。
- 原因族覆盖、出版社集中度和年度趋势应同时报告记录口径与论文口径。
- 2023 专项必须分别报告通知记录、唯一 DOI 和可链接论文。
