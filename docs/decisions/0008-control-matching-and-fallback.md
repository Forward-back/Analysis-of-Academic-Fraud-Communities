# 0008：非撤稿对照匹配与退化规则

- 状态：已接受
- 日期：2026-11-18
- 决策范围：1:2 非撤稿对照候选、主题递进和出版社退化

## 基本规则

- 每篇合格撤稿论文最多匹配 2 篇非撤稿论文。
- 主层保持发表年、期刊来源和文献类型精确。
- 候选必须在 OpenAlex 中具有 `CN` 机构关联且 `is_retracted=false`。
- 对照作品 ID 和 DOI 均全局去重。
- 案例按候选稀缺度从小到大分配，固定种子和作品 ID 顺序保证可复现。

## 主题递进

1. `primary_topic`。
2. `subfield`。
3. `field`。
4. `domain`。
5. `source_only`：仍要求期刊、发表年和文献类型相同。

优先选择至少 2 个候选的最高主题层。

## 出版社退化

同期刊年度层不足时，使用：

- 发表年精确。
- 文献类型精确。
- 学科 `field` 精确。
- 出版社精确。
- 仅使用已抓取的随机候选池，不按结果变量重新抽样。

该层标记为 `publisher_fallback`。

## 当前结果

- 可匹配案例：24,660。
- 两篇对照：22,090。
- 一篇对照：108。
- 零篇对照：2,462。
- 对照作品：44,288，无作品 ID 或非空 DOI 重复。
- 出版社退化补入：3,813 篇。

零对照案例保留在审计表，不插补或重复使用其他作品的对照。

## 解释边界

- 对照是观察性可比基线，不是因果控制组。
- `publisher_fallback` 与精确主题层分开报告。
- 零、一篇、两篇匹配比例必须进入最终结果限制。
