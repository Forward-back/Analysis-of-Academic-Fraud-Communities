# 0005：OpenAlex 匹配与分层分析样本

- 状态：已接受
- 日期：2026-11-18
- 决策范围：OpenAlex DOI 匹配、大陆确认、机构完整和网络可用子集

## 背景

中国大陆候选共 26,526 个 DOI。全量 OpenAlex 抓取完成 266 批，所有批次
HTTP 200。严格 DOI 匹配结果：

- 单一精确作品：26,497。
- 同一 DOI 返回多个精确作品：4。
- 没有单一精确作品：25。
- 其中 OpenAlex 返回了 7 个近似但非精确 DOI 的作品。
- 没有网络失败或 JSON 失败批次。

为避免静默改变论文身份，本版不把近似 DOI、撤稿通知 DOI 或题名相似结果
自动升级为原论文匹配。

## 匹配决策

- 主链接只接受单一、规范化 DOI 精确匹配。
- 多作品精确匹配保留在失败审计，不随机选择其中一篇。
- 近似 DOI 作品只保留审计，不进入主面板。
- 未找到不通过标题、作者姓名、PubMed ID 或人工判断补匹配。
- 后续如建立 DOI 别名和替换关系表，须单独冻结来源、规则和 ADR。

## 分析子集

### 大陆确认样本

- 至少一个作者机构国家代码为 `CN`。
- 当前为 24,978 篇。
- `HK`、`MO`、`TW` 机构单列；仅有港澳台机构而不含 `CN` 的 94 篇排除。
- 同时含大陆和港澳台机构的 313 篇保留，并保留港澳台机构标记。

### 机构完整样本

- 所有作者至少有一个 OpenAlex 机构 ID。
- 排除 4 篇标题严重冲突后，当前为 21,842 篇。
- 用于机构层级、合作地理和机构距离主分析。

### 网络完整样本

- 所有作者有 OpenAlex 作者 ID。
- 所有作者至少有一个机构 ID。
- 排除 4 篇标题严重冲突后，当前为 14,827 篇。
- 用于作者 ID 合作网络、重复合作和社群筛选。
- 不得把该子集结果表述为全部大陆确认论文的全网络结论。

## 覆盖结果

| 指标 | 数量 | 率 |
|---|---:|---:|
| 单一精确 DOI 匹配 | 26,497 | 99.89% |
| OpenAlex 确认大陆 | 24,978 | 94.27% |
| 大陆确认且机构完整 | 21,842 | 87.45% |
| 大陆确认且网络完整 | 14,827 | 59.36% / 最终主样本 59.37% |

标题冲突排除规则见 [ADR 0006](0006-title-linkage-exclusions.md)。
机构完整率通过 70% 质量门槛。网络完整率明显低于机构完整率，
网络分析须同时报告覆盖限制和姓名加机构审计网络结果。

## 解释影响

- 论文层机构与地理模型使用机构完整样本。
- 团队人数可在全部大陆确认样本中单独描述。
- 网络层使用网络完整样本，并与全部大陆确认样本的合作指标并列解释。
- 匹配非撤稿论文仍须按同一分析层级报告，不能混用分母。
