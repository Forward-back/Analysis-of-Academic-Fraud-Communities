# 0001：中国大陆资源位势合作结构与资助审计

- 状态：已接受
- 日期：2026-11-17

## 背景

课程综合项目需要在有限时间内形成完整证据链。原有方案同时覆盖全球样本、四类原因族、多个治理层级、全量网络、混合模型和资助分析，范围过大。

中国机构层级、省级地理和国内资助来源只有在中国大陆样本中才具有一致解释。Retraction Watch 的 `Country` 字段只能用于候选筛选，最终中国大陆身份需要由 OpenAlex 作者机构中的 `CN` 代码确认。

2023 年撤稿通知高度集中于出版社特刊清理事件。若不单独处理，出版社批量治理行动会被误写成国家层面的学术不端趋势。

## 决策

1. 主样本为中国大陆关联撤稿论文；香港、澳门和台湾机构分别处理，不并入中国大陆样本。
2. 主窗口按撤稿年份定义为 `2012–2025` 年。每篇撤稿论文最多匹配两篇非撤稿论文，匹配变量为原论文发表年份、学科、期刊来源和文献类型，层内不足时按预先定义的规则退化。
3. 主结构指标为团队机构层级、合作地理层级和团队规模。机构层级在 `2012–2016` 使用 `985/211` 身份，在 `2017–2025` 使用双一流身份。
4. 主推断原因族为出版流程操纵、图像完整性和剽窃/署名；数据完整性作为探索性分析。严格错误/信息不足撤稿论文作为参照组。
5. 论文层混合模型、网络置换零模型和条件 logistic 分别承担主比较、结构检验和稳健性复核。
6. 候选社群以跨论文重复合作超额为主指标筛选，固定选取 25 个待核查社群。每社群最多按分层随机规则抽取 20 篇论文。
7. 资助审计在第二阶段进行，以资助组合重叠为主指标。金额只采用官方可核验项目记录，不参与社群筛选或主模型。
8. 2023 年峰值作为独立的出版社特刊治理与批量撤稿事件拆解，并使用 Crossref 期刊年度发表量作为分母。

## 后果

- 项目需要完成 DOI、作者、机构和地理实体链接，数据工程量高于纯撤稿描述研究。
- 中国大陆主样本约 26,526 个原论文 DOI，仍需 OpenAlex 精确匹配后才能确定网络样本。
- 数据完整性族样本不足 `1,000`，不能与其他原因族等权解释。
- 非撤稿对照只能降低同出版情境差异，不能把观察性关联升级为因果结论。
- 2023 专项必须区分论文发表时间与撤稿通知时间，不能把集中清理解释为不端发生率上升。
- 项目需要申请 OpenAlex API key、缓存响应，并对期刊、机构层级和地理映射做人工抽检。
