# 网络团队构成零模型

> 状态：1,000 次置换已完成  
> 样本：14,827 篇网络完整论文  
> 随机种子：`20261117`

## 零模型

每篇论文保持原团队人数。作者从“撤稿年份 × 学科 `field` × 出版社”层内抽取，
不放回且选择概率与该作者在原层内的出现次数成比例。置换保持论文数、团队人数、
年份、学科和出版社分布。

该零模型不保持每位作者原始的论文次数或度分布。结果用于检验重复合作是否超过
团队构成与出版情境的可解释水平，不表示因果效应。

## 全局重复合作

| 指标 | 观察值 | 零模型均值 | 零模型 95% 区间 |

| 重复边 | 4,587 | 4,008.55 | 3,864.98–4,153.00 |
| 跨年重复边 | 2,123 | 261.09 | 235.00–288.05 |

- 重复边超额：578.45。
- 重复边 `z = 7.70`。

跨年重复超额远大于同年重复，说明观察网络中的持续合作关系不是仅由单年团队规模解释。

## 解释边界

- 置换使用发布后确定的团队与出版情境，不是因果识别。
- 主零模型不保持作者度；作者度保持配置模型作为敏感性检查。
- 原因族 FDR 覆盖当前 8 个比较组，未归类组结果不进入原因解释。

## 作者度保持敏感性

另做 200 次随机端点配对：保留观察到的作者加权共同作者度、边出现次数和节点集合，
随机重配共作者关系。该模型不保留论文团队、年份、学科或出版社结构，因此比主模型
更强，只用于敏感性检查。

- 观察重复边：4,587。
- 度保持零模型均值：32.52。
- 零模型 95% 区间：21.93–43.05。
- 超额：4,554.49；`z = 775.27`。
- 单侧置换 `p = 0.005`，为 200 次置换的分辨率下限。
- 平均自环：5.75/次，自环已排除。

结果说明重复合作边远高于仅保留作者度的随机配置。不能把这个差值解释为单一机制的
因果效应；团队构成、年份、学科和出版社结构都被该敏感性模型移除。
