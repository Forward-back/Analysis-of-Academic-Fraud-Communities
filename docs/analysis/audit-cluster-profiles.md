- 审计簇表示重复合作与出版生态需要进一步核验的聚合结构。
- 共同署名不等于共同责任。
- 出版社和期刊集中可能来自学科、特刊、撤稿批次或平台清理，不能直接作不端判断。
- 簇画像不包含资助动机、个人排行榜或机构定性。
- 审计簇的论文很小，仅 308 篇，适合线索审计，不适合估计总体比例。
- 网络完整率与原因族覆盖偏差仍适用于全部画像。
