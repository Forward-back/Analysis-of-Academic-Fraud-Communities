# 主要限制

> 状态：当前版本

## 数据覆盖

- 撤稿通知不是所有问题论文的完整普查。
- DOI 缺失存在年份和出版社差异。
- OpenAlex 作者与机构覆盖不完整。
- 资助元数据覆盖低，无记录不等于无资助。

## 实体识别

- OpenAlex 作者 ID 可能错误合并或拆分。
- 同一作者多机构挂靠影响机构层级和地理分类。
- 机构更名、附属医院和分校需要人工映射。
- 中英文机构名称不能直接作为主键。

## 研究设计

- 原因标签来自通知，不是正式调查裁决。
- 原因族允许重叠，难以估计互斥原因净效应。
- 匹配只能改善可比性，不能消除全部混杂。
- 撤稿原因形成于论文发表后，不能按因果处理。

## 时间与事件

- 撤稿通知日期不是问题发生日期。
- 2023 年由出版社批次主导。
- 2020 年前后的出版环境和特刊模式变化影响趋势。

## 资助

- 项目金额不能唯一分摊到论文。
- 多基金署名与真实资金贡献可能不一致。
- 公开项目库覆盖和许可限制。

## 解释

所有结果限定在中国大陆关联撤稿样本及匹配样本范围内。不能外推为全球规律、国家不端率或机构诚信排名。
