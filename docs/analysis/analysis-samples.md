# 分析样本冻结与选择审计

> 状态：P0 已完成
> 完成日期：2026-11-21
> 样本：24,974 篇中国大陆主分析撤稿论文、44,287 篇最终非撤稿对照

## 目的

本阶段不生成原因族效应，只确定后续每个结果使用哪一层样本，并量化零对照、
对照机构字段缺失和网络完整率造成的选择差异。

所有样本均由逐论文审计表生成。缺失机构身份或地理位置不插补；无法进入某一
完整案例分析时保留原样本，并用显式标记排除。

## 冻结样本

| 样本名 | 论文数 | 用途 |
|---|---:|---|
| `descriptive_full` | 24,974 | 全部大陆主分析论文的描述与覆盖审计 |
| `matched_any_control` | 22,198 | 至少有一篇最终对照的匹配案例 |
| `team_size_compare` | 22,198 | 使用案例与对照团队人数进行比较 |
| `matched_institution_compare` | 12,373 | 案例机构完整，且每篇关联对照的机构字段完整 |
| `network_complete` | 14,827 | 全部作者 ID 与机构信息完整的网络样本 |
| `network_excluded` | 10,147 | 未进入网络完整子集的大陆主分析论文 |

主分析论文中，0/1/2 篇对照分别为 `2,776/109/22,089`。其中 314 篇没有可用匹配层，
2,462 篇虽有匹配层但最终未获得对照。

## 零对照选择

零对照案例不是随机子集：

- 2,776 篇零对照论文中，1,594 篇撤稿于 2023 年，占 57.42%。
- 有对照的 22,198 篇论文中，2023 年占 37.99%。
- 出版流程族零对照率为 13.10%，图像完整性族为 0.69%。
- 零对照案例平均团队人数 3.28，有对照案例平均 4.33。
- 314 篇无匹配层案例均缺期刊来源，平均团队人数 1.81。

因此，论文层比较不能只报告有对照案例，也不能把零对照作为普通缺失忽略。
后续结果至少同时报告全样本匹配完整性、有对照案例结果和零对照选择差异。

## 对照机构字段缺口

对照机构字段有两种缺口：

1. 对照作者本身没有可用机构 ID。
2. 作者有机构 ID，但机构缺城市、坐标或 ROR 等富化元数据。

最终 44,287 篇对照中：

| 状态 | 对照作品 |
|---|---:|
| 字段完整 | 34,945 |
| 仅作者机构 ID 缺口 | 4,658 |
| 仅富化机构元数据缺口 | 4,077 |
| 两类缺口并存 | 607 |
| 任一缺口 | 9,342 |

对应到匹配案例：

- 8,149 篇至少受一篇对照字段缺口影响。
- 14,049 篇的每篇对照机构字段完整。
- 再要求案例机构完整后，可用于机构与地理比较的样本为 12,373 篇。

先前文档中的 4,267 篇只统计“机构富化元数据缺失”的影响；本阶段的 8,149 篇同时
计入对照作者机构 ID 缺失。两个数字口径不同，不能互相替代。

## 网络完整率选择

网络完整论文 14,827 篇，未纳入 10,147 篇。排除样本并非只缺少量字段：

| 指标 | 网络完整 | 网络排除 |
|---|---:|---:|
| 论文数 | 14,827 | 10,147 |
| 平均团队人数 | 3.55 | 5.43 |
| 出版流程族占比 | 61.75% | 54.09% |
| 图像完整性族占比 | 10.51% | 17.35% |
| 剽窃/署名族占比 | 10.84% | 13.87% |

团队人数标准化均值差为 `-0.640`，即网络完整样本的团队明显更小。图像完整性族
网络覆盖率为 46.97%，剽窃/署名族为 53.32%，均低于出版流程族的 62.52%。

出版社差异同样明显：Wiley 网络覆盖率为 46.61%，Verduci Editore 为 0。
因此网络结论必须明确限定为网络完整子集，并报告原因族和出版社选择差异。

## 解释边界

- 12,373 篇是当前机构与地理论文比较的完整案例样本，不是全部 22,198 篇匹配案例。
- 未插补对照机构字段；后续不得把完整案例结果写成全部撤稿论文的结论。
- 零对照与网络排除均与年份、原因族、团队规模或出版社相关，不能视为随机缺失。
- 本阶段只冻结样本和选择审计，不包含原因族效应、模型显著性判断或因果解释。
- OpenAlex 机构接口恢复后补齐字段，仍需作为敏感性复核，不追溯修改本阶段分母。
