# 边界与伦理

> 状态：已冻结

## 术语边界

- **撤稿关联合作网络**：共同署名同一篇撤稿论文，不表示共同造假。
- **原因族**：通知中问题标签的语义分组，不是正式学术不端认定。
- **风险**：出版社面临的核查成本与治理风险，不是作者不端概率。
- **待核查社群**：按结构规则筛选的审计对象，不是“高风险社群”。
- **治理线索**：需要进一步验证的聚合证据，不是责任判断。

## 结论边界

- 使用“关联”“对应”“结构差异”，不使用因果“塑造”或“传播”。
- 不使用无总发表量分母的撤稿率。
- 不把 2023 年通知数量解释为中国学术不端爆发。
- 不按作者姓名展示撤稿次数或排序。
- 机构与出版社结果只在撤稿样本和匹配样本范围内解释。

## 资助审计边界

- 无资助记录不等于无资助。
- 金额只采用官方项目库或官方项目页面。
- 缺失金额不补零、不均值插补、不按论文分摊项目总金额。
- 金额只作描述，不作动机推断或风险排序。

## 数据与隐私

- OpenAlex 使用 CC0。
- Retraction Watch 原始 CSV 的再发布许可仍待确认。
- 公开材料优先提供脚本、聚合指标和派生数据。
- 不绕过付费墙批量抓取全文。
- 公开作者级结果前进行最小必要核验和聚合。

## 可复现要求

- 随机过程固定种子。
- API 响应缓存。
- 原始文件记录哈希与观察日期。
- 所有报告数字可追溯到 `data/outputs/`。
- 文档区分计划、进行中和已完成。
