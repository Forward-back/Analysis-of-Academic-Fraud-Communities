# 研究范围与假设

> 状态：已冻结

## 主样本

- Retraction Watch 中 `RetractionNature == "Retraction"`。
- 撤稿年份 `2012–2025`。
- RWDB 国家字段用于候选筛选。
- OpenAlex 至少一个作者机构国家代码为 `CN`，作为中国大陆关联最终确认。
- 香港、澳门、台湾机构分别标记，不并入中国大陆样本。

## 对照样本

- OpenAlex 非撤稿论文。
- 至少一个 `CN` 机构。
- 按原论文发表年、期刊和文献类型精确匹配。
- 学科按 `primary_topic`、`subfield`、`field`、`domain` 递进匹配。
- 每篇撤稿论文最多 2 篇对照。

## 分析单位

| 单位 | 键 | 用途 |
|---|---|---|
| 通知记录 | `Record ID` | 来源和通知类型审计 |
| 撤稿论文 | 规范化 DOI | 原因族、匹配与论文模型 |
| 作者关系 | DOI + OpenAlex 作者 ID | 团队、机构与网络 |
| 社群 | 稳定社群编号 | 结构画像和第二阶段审计 |
| 资助项目 | 官方项目编号 | 资助组合审计 |

## 原因族

- 主推断：出版流程操纵、图像完整性、剽窃/署名。
- 探索：数据完整性。
- 参照：严格错误/信息不足。
- 多标签允许重叠；不构造互斥主因。

## 研究假设

| 编号 | 假设 | 主要证据 |
|---|---|---|
| H1 | 出版流程操纵族相对匹配非撤稿论文更可能出现跨层级和跨省合作 | 论文层模型、网络边比例 |
| H2 | 图像完整性族更可能集中在同机构或同省合作，但允许结果推翻 | 地理层级与距离模型 |
| H3 | 跨论文重复合作超额在出版流程操纵族中更明显 | 重复合作边与零模型 |
| H4 | 2023 峰值主要由出版社特刊治理与集中撤稿驱动 | 批次、期刊、原论文年份与外部证据 |
| H5 | 待核查社群可能具有重复资助机构或项目编号，但覆盖不足时只作探索 | 第二阶段资助组合指标 |

假设用于组织证据，不是预计显著结论。
