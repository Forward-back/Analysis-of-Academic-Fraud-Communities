# 初步数据探索报告

## 一、探索范围

- 数据文件：`raw/retractions.csv`。
- 实际获取日期：2026-11-04。
- 原始记录：73,597 条。
- 主事件池：`RetractionNature == "Retraction"`，68,155 条。
- 核心窗口：2012–2025 年，52,638 条。
- 原因字典：严格 v1 草稿。
- 本阶段未抓取 OpenAlex，因此不报告作者 ID 网络指标。

完整汇总表在 `outputs/`，六张图在 `figures/`。所有数字可由
`scripts/run_initial_eda.ps1` 重跑生成。

1756-06-24 至 2026-10-15，其中只有一条早于 1900 年的历史记录，不影响核心窗口。

![年度通知类型](figures/01_records_by_year_nature.png)

年度曲线显示 2010–2011 年有一次明显批量事件，2023 年又有一次远高于常规水平的撤稿峰值。
这两段都可能由少数大型批次主导，不能直接当作逐年自然增长趋势。

## 三、DOI 覆盖不是均匀的

核心窗口总体 DOI 覆盖率为 93.95%，但年度差异很大：

- 2012–2015 年约为 94%–96%。
- 2017 年降至 82.94%。
- 2019 年降至 60.54%。
- 2022–2025 年恢复到 99% 以上。

![年度 DOI 覆盖](figures/02_doi_coverage_by_year.png)

2019 年的大量缺失 DOI 会使 OpenAlex 匹配样本偏向上报规范更完整的记录。正式分析必须：

1. 按年份、原因族、出版社和文章类型分层报告匹配率。
2. 比较匹配与未匹配记录的特征差异。
3. 把匹配率低的分层结论降级为探索性。
4. 不把 60.54% 的年度覆盖率当作随机缺失。

## 五、2023 年峰值高度集中

2023 年共有 13,371 条核心窗口撤稿记录，其中：

- Hindawi 记录 9,673 条，占该年 72.34%。
- 出版流程操纵族记录 11,132 条，占该年 83.25%。
- 剽窃/署名族记录 1,057 条。
- 图像完整性族记录 937 条。

![原因族年度趋势](figures/06_reason_family_trends_core.png)

这提示 2023 年峰值很可能反映出版社批量撤稿和特刊治理事件，而不一定代表所有出版社、
所有学科的同步变化。因此网络和模型至少需要：

- 按出版社分层。
- 去掉最大若干连通组件后重算。
- 对 2023 年单独拆解。
- 比较事件前、事件期和事件后。
- 报告无论是否包含 2023 年都稳定与不稳定的结论。

## 六、作者规模适合做结构分析，但还不能建网络

核心窗口原始作者数分布：

- 中位数：4。
- 第 75 百分位：6。
- 第 90 百分位：8。
- 第 95 百分位：10。
- 最大：88。
- 无空作者列表。

![作者数分布](figures/05_author_count_distribution_core.png)

作者规模有足够变化，可以支持团队规模控制和大团队敏感性分析。但原始作者字段没有稳定 ID，
当前只能作为描述变量，不能据此宣称得到真实合作网络。下一步必须使用 OpenAlex 作者 ID
并审计匹配率。

## 七、出版社和学科集中度

核心窗口记录数最多的原始出版社为：

| 出版社原文 | 记录数 |
|---|---:|
| Hindawi | 11,480 |
| Elsevier | 5,835 |
| Springer | 4,194 |
| Wiley | 3,527 |
| Springer - Nature Publishing Group | 2,785 |

出版社名称存在集团、子品牌和并购关系混用，正式模型需要标准化。出版社记录量也不能解释为
出版社撤稿率，因为缺少各出版社的总发表量分母。

学科前缀中，(B/T) 有 18,823 条，(BLS) 有 17,170 条，(HSC) 有 8,214 条，
其余为 PHY、SOC、ENV 和 HUM。学科分布说明结果不能被解释为所有学科的普遍规律。

## 八、撤稿时滞

核心窗口中有效日期可计算 52,638 条：

- 发表后一年内撤稿：15,530 条，占 29.50%。
- 一到三年：22,338 条，占 42.44%。
- 三到五年：6,882 条，占 13.07%。
- 五年以上：7,887 条，占 14.98%。
- 负时滞：1 条。

撤稿时滞可以作为控制变量或描述性结果。负时滞记录应在建模前单独核查，不能用算法强行修正。

## 九、对研究设计的含义

1. **选题可行。** 原因族和出版治理信息的覆盖足以开展描述和结构比较。
2. **网络可行性尚未证明。** 需要先完成 OpenAlex DOI 匹配，至少核对匹配率、
   作者 ID 缺失和同一 ORCID 多 ID 的冲突。
3. **不能把原因族作为互斥分类。** 主分析保留多标签，另做窄定义敏感性分析。
4. **2023 年不能与常规年份同权解释。** 需要出版社分层、事件拆解和组件剔除。
5. **DOI 缺失存在年度选择偏差。** 2019 年尤其需要覆盖审计。
6. **管理结论应停在筛查线索。** 当前证据不能支持个人定罪或机构诚信排名。
