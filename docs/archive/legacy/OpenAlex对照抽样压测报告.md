# OpenAlex 非撤稿对照抽样压测报告

## 范围

- 压测日期：2026-11-17。
- 来源案例：500 DOI 压测中已确认中国大陆机构、具有期刊、年份、文献类型和主题字段的撤稿论文。
- 测试层级：随机抽取 25 个“期刊 + 发表年 + 文献类型”层。
- 候选条件：非撤稿、中国大陆机构关联、同期刊、同发表年、同文献类型。
- 原始响应缓存：`cache/openalex_control_pressure_test/`。
- 汇总结果：`outputs/openalex_control_pressure_test_25.json`。

## 结果

| 指标 | 结果 |
|---|---:|
| 请求层数 | 25 |
| 成功层数 | 25 |
| 案例数 | 47 |
| 返回对照 | 461 |
| 对照确认中国大陆机构 | 100% |
| 同 `primary_topic` 且至少 2 个候选 | 5/47 |
| 同 `subfield` 且至少 2 个候选 | 18/47 |
| 同 `field` 且至少 2 个候选 | 38/47 |
| 同 `domain` 且至少 2 个候选 | 43/47 |

## 结论

1. 期刊年度层抽样可行，且中国大陆机构过滤有效。
2. 精确主题匹配过稀，不能把 `primary_topic` 完全相同作为所有案例的硬性门槛。
3. 采用主题、子领域、领域、学科域的递进匹配；期刊、发表年和文献类型保持精确。
4. 小型层和 `type=retraction` 等特殊类型需要按发表年、学科领域和出版社退化。
5. OpenAlex 单次 `sample` 实测最多返回 25 条，大层需要多个种子批次累计并全局去重。
