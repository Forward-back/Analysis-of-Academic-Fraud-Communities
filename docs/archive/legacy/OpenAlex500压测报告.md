## 解释

1. DOI 批量匹配可行，时间与请求量可控。
2. RWDB 国家字段不能作为最终中国大陆身份。约 7.4% 候选无法由 OpenAlex 机构国家确认。
3. 机构层级与地理结构必须使用机构完整子集，缺失机构论文仅做敏感性分析。
4. 资助机构和项目编号覆盖不足，不支持全样本资助主分析；资助审计只适合第二阶段待核查社群。
5. 本轮未测试机构地理字段、作者 ID 冲突和非撤稿对照抽样，下一阶段需单独审计。
