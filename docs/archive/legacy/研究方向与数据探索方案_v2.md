# 研究方向与数据探索方案 v2

## 一、项目定位

**题目方向：中国大陆撤稿原因与合作资源位势网络研究**

项目以 Retraction Watch 撤稿记录为事件与原因主表，以 OpenAlex 为作者、机构、地理、学科和资助元数据主表，以 Crossref 补充更新关系、资助元数据与期刊年度发表量。

目标是形成一条可复核的证据链，而不是给作者、机构或国家排名：

1. 不同撤稿原因族是否对应不同的团队机构层级与合作地理结构。
2. 待核查作者合作社群是否表现出跨论文重复合作超额。
3. 2023 年撤稿峰为何出现，是否主要由出版社特刊治理和批量撤稿驱动。
4. 待核查社群的资助组合是否具有可追溯的共享结构。

研究只讨论撤稿样本中的结构关联，不使用因果“塑造”“传播”措辞，不推断国家层面学术不端发生率。

## 二、研究范围

- 主样本：至少一个 OpenAlex 作者机构的国家代码为 `CN` 的中国大陆关联撤稿论文。
- 撤稿入选窗口：撤稿年份 `2012–2025`。
- 港澳台机构分开标记，不并入中国大陆样本。
- 全球其余数据只用于背景趋势与稳健性比较。
- 2026 年作为不完整年度排除。
- 原始数据以当前唯一 CSV 为冻结副本，保留哈希与观察日期。

## 三、核心问题与假设

### RQ1

中国大陆撤稿论文中，出版流程操纵、图像完整性和剽窃/署名三类原因族，相对匹配非撤稿论文，是否呈现不同的机构层级与地理合作结构？

### RQ2

作者合作网络中，哪些社群存在相对零模型显著更高的跨论文重复合作，并呈现哪些机构层级、地理和出版社集中特征？

### RQ3

2023 年撤稿峰在出版社、期刊、原论文发表年份、原因标签和通知时间上如何构成？公开资料是否支持“特刊治理与批量撤稿事件”的解释？

### RQ4

筛选出的待核查社群是否表现出比匹配基线更强的资助机构和项目组合重叠？官方可核验金额覆盖到什么程度？

### 工作假设

| 编号 | 假设 |
|---|---|
| H1 | 出版流程操纵族相对匹配非撤稿论文更可能出现跨层级和跨省合作。 |
| H2 | 图像完整性族更可能集中在同机构或同省合作结构，但允许结果推翻。 |
| H3 | 跨论文重复合作超额在出版流程操纵族中更明显。 |
| H4 | 2023 峰值主要反映出版社集中调查和批量撤稿，不是通知数代表的同期不端发生率上升。 |
| H5 | 待核查社群相对匹配基线可能表现出资助机构或项目编号的重复重叠，但覆盖不足时只作探索。 |

## 四、数据与样本

### 当前数据事实

- 通知记录：73,597。
- Retraction 记录：68,155。
- `2012–2025` 核心记录：52,638。
- 中国大陆候选记录：26,763。
- 中国大陆候选唯一 DOI：26,526。
- 严格错误/信息不足对照组唯一 DOI：3,179。
- 数据完整性族约 682 个 DOI，只作探索性分析。

### OpenAlex 压测

- 500 个中国大陆候选 DOI 全部精确匹配。
- 作者记录机构字段覆盖 88.4%。
- 原始机构文本覆盖 97.1%。
- 论文全部作者有机构 ID：81.6%。
- OpenAlex 明确确认 `CN`：92.6%。
- 资助机构记录覆盖 32.4%，项目编号覆盖 25.0%。
- 5 批共 500 个 DOI 完成时间约 19 秒。

### 对照匹配

- 每篇撤稿论文最多匹配 2 篇中国大陆关联非撤稿论文。
- 撤稿论文按撤稿年份入选；对照按原论文发表年份匹配。
- 第一层精确匹配期刊、发表年和文献类型。
- 学科按 `primary_topic`、`subfield`、`field`、`domain` 递进匹配。
- 同层不足时退化为发表年、学科 `field` 和出版社。
- 主分析允许作者重叠；稳健性分析排除与任一撤稿论文共享作者 ID 的对照。
- 每层使用固定种子，多个 25 条样本批次累计并去重。

### 分析单位

| 层级 | 唯一键 | 用途 |
|---|---|---|
| 通知记录 | `Record ID` | 来源审计与通知类型 |
| 撤稿论文 | 规范化原论文 DOI | 原因族、匹配与论文层模型 |
| 作者-论文关系 | 论文 DOI + OpenAlex 作者 ID | 团队与网络 |
| 社群 | 稳定社群 ID | 结构画像与第二阶段审计 |
| 资助项目 | 官方项目编号 | 第二阶段资助组合 |

## 五、变量构造

### 原因族

- 主推断：出版流程操纵、图像完整性、剽窃/署名。
- 探索：数据完整性。
- 参照：严格错误/信息不足撤稿论文。
- 多标签分别建模，允许同篇论文进入多个原因族分析。
- 未归类仅作覆盖说明。

### 机构层级

- `2012–2016` 使用 `985/211` 身份。
- `2017–2025` 使用双一流身份。
- 分校、附属医院和研究院沿主线机构归并。
- 计算国家重点高校作者占比、跨层级合作和跨层级边比例。
- 另用固定名单做敏感性分析。

### 合作地理

- 单一城市。
- 同省多城市。
- 境内跨省。
- 中国机构参与的国际合作。
- 计算去重机构间中位与最大距离、跨省边比例和跨国边比例。
- 港澳台机构单独标记。

### 机构缺失

- 主结构分析要求全部作者均有机构 ID。
- 团队人数可在全部已确认 `CN` 论文中分析。
- 机构缺失论文不插补，只进入覆盖报告和敏感性分析。

## 六、分析路径

### 第一层：覆盖与描述

1. 通知、论文、作者三个层级分别计数。
2. 中国大陆候选、OpenAlex 确认、机构完整三个样本量分层报告。
3. 原因族覆盖、共现和年度趋势。
4. 机构层级、地理层级和团队规模分布。
5. 匹配前后协变量平衡与覆盖差异。

### 第二层：论文层匹配模型

- 二元结构结果使用混合效应 logistic。
- 团队人数使用负二项或对数线性混合模型。
- 机构距离使用对数变换后的混合模型。
- 匹配组作随机截距，年份使用平滑项。
- 学科、文献类型和团队规模按具体结果选择性控制。
- 三主原因族分别对比匹配非撤稿基线，并做 FDR 校正。

### 第三层：网络与社群

- 使用 OpenAlex 作者 ID 构建作者合作投影。
- 计算跨机构、跨层级、跨省和跨国边比例。
- 以论文团队构成、年份、学科、出版社和样本规模构造置换零模型。
- 主筛选指标为跨论文重复合作超额。
- 社群检测使用 Leiden，分辨率扫描和固定种子检查稳定性。
- 固定选取 25 个待核查社群。

### 第四层：稳健性

- 条件 logistic 检查原因族归属与结构特征的方向。
- 用单一主机构替代全部机构重算。
- 排除作者重叠对照重算。
- 用固定机构层级名单重算。
- 剔除前五大批次重算。
- 检查 2023 年是否主导全部结论。

## 七、2023 年批次事件专项

### 本地事实

- 中国大陆关联 2023 撤稿记录：10,697。
- Hindawi 记录：8,626，占 80.6%。
- 原论文发表于 2022 年：6,988。
- 原论文发表于 2021 年：2,241。
- 研究论文：9,629。
- 高频标签包括出版社调查、第三方调查、结果不可靠、数据问题、同行评审问题、Paper Mill 和计算机生成内容。

### 分析

1. 按撤稿月份、周和同日批次重建时间线。
2. 拆分 Hindawi 与非 Hindawi、特刊与非特刊。
3. 对 2023 年高频前 20 个期刊获取 `2018–2025` 年 Crossref 年度发表量。
4. 区分原论文发表时间与撤稿通知时间。
5. 结合 Wiley、Clarivate、出版社公告、公开撤稿通知和论文工厂研究解释机制。
6. 先输出描述性事件曲线与来源证据表，不先写因果结论。

### 解释边界

2023 峰值只解释为出版社特刊治理、集中调查和批量撤稿事件，不解释为中国学术不端爆发。

## 八、第二阶段资助审计

### 样本

- 25 个待核查社群。
- 每社群最多 20 篇，按撤稿年份和出版社分层随机抽取。
- 总数最多约 500 篇。
- 主基线为匹配非撤稿论文，内部基线为未入选撤稿社群。

### 指标

- 有明确资助元数据的论文比例。
- 资助机构多样性。
- 跨论文重复资助机构比例。
- 同一项目编号复用比例。
- 社群资助集中度。
- 官方可核验金额记录数与覆盖率。

### 金额规则

- 只采用官方项目库或官方项目页面。
- 保留 URL、查询日期、币种和原文证据。
- 不把缺失金额当零。
- 不把项目总金额平均分摊到论文。
- 金额只做案例附录，不参与社群筛选或主模型。

## 十一、质量门槛

- DOI 精确匹配率低于 75% 时，作者网络降级。
- 匹配率 60%–75% 时，主结论写为探索性并报告分层覆盖。
- 机构完整子集低于 70% 时，机构层级和地理结论降级。
- 资助元数据覆盖低于 50% 时，资助只放附录或专项。
- 原因族小于 1,000 个 DOI 时，不作等权主推断。
- 任何核心结论同时报告全样本、剔除前五大批次和排除作者重叠对照。
- 每个报告数字必须能定位到输出文件与脚本步骤。

## 十二、停止条件

- 若 OpenAlex 全量匹配、机构确认或对照匹配出现严重选择偏差，停止扩大模型，只保留覆盖审计、原因描述与 2023 事件分析。
- 若网络被单一出版社年度批次完全支配，主网络结论降级为事件分析。
- 若模型无法收敛，改用固定效应、简化随机效应或分层描述，并记录原因。
- 若第二阶段全文获取受许可限制，只使用公开元数据和官方项目记录，不绕过付费墙。

## 十三、答辩主线

1. 出版社面对撤稿时，真正要分配的是不同核查能力。
2. 中国大陆样本的原因族并不共享同一种合作资源结构。
3. 2023 峰值主要由出版社特刊治理和集中撤稿驱动，不能直接读作不端增长。
4. 少数待核查社群存在跨论文重复合作，并可进一步审计资助组合。
5. 管理建议只到筛查线索和流程配置，不生成个人或机构风险排行榜。
