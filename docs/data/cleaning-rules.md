# 清洗规则

> 状态：核心规则已冻结

## 日期

- Retraction Watch 日期格式为月/日/年，先删除时间部分。
- 使用 `%m/%d/%Y` 解析。
- 无法解析保留为缺失，不以当前日期补齐。
- 主窗口按撤稿年份筛选。

## DOI

1. 去除首尾空格。
2. 转小写。
3. 删除 `https://doi.org/`、`http://doi.org/` 和 `doi:` 前缀。
4. 删除末尾句点、逗号和分号。
5. 空白、`unavailable`、`N/A` 和 `NA` 统一为缺失。

## 通知与论文折叠

- 主事件只保留 `Retraction`。
- DOI 级论文合并同一 DOI 的多条通知。
- 原因标签取并集。
- 最早撤稿日期作为时间索引。
- 保留全部 `Record ID` 供审计。
- 不直接删除后续通知。

## 原因族

- 保留原始 `Reason`。
- 一个标签可映射多个问题领域，使用长表保存，不压成单一类别。
- 调查、法律和行政状态作为上下文，不当作原因领域。
- 主分析使用 `substantive_finding` 的窄定义；疑虑和错误标签只进入宽定义敏感性分析。
- 严格错误/信息不足组是论文层派生参照，不能与窄定义实质分析族同时成立。
- `unclassified` 只用于覆盖说明，不是原因族。
- 字典修订递增版本，不覆盖旧版。

## 中国大陆确认

- RWDB `Country` 只用于候选筛选。
- OpenAlex 至少一个作者机构国家代码为 `CN`。
- 港澳台机构分别标记。
- 仅靠姓名、中文题名或邮箱不推断中国大陆身份。

## 机构完整子集

- 主结构分析要求全部作者均有至少一个机构 ID。
- 缺失机构不插补。
- 原始机构文本可用于敏感性恢复，但不进入主模型。
- 团队人数可以在全部确认 `CN` 论文中单独分析。

## 机构层级

- `2012–2016` 使用 985/211 名单。
- `2017–2025` 使用双一流名单。
- 分校、附属医院和研究院映射到主线机构。
- 未匹配机构保留为 `unknown`，不推断为国家重点机构。

## 地理

- 使用 OpenAlex 机构经纬度计算球面距离。
- 地理层级按论文去重机构集合判定。
- 同城、同省、跨省和国际按最高跨度归类。
- 港澳台单独标记。

## 随机性

- 抽样、匹配和零模型使用固定种子。
- 所有随机样本保存清单或哈希。
- 抽样后不按结果好坏重新抽取。
