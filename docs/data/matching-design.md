# 非撤稿对照匹配

> 状态：已冻结

## 目的

匹配非撤稿论文用于估计同发表年、期刊、文献类型和相近学科下的合作结构基线。它不是因果控制组，也不能证明论文经历完全相同。

## 比例

- 每篇撤稿论文最多 2 篇对照。
- 层内不足时最多 1 篇。
- 对照全局去重。
- 主分析允许对照与撤稿论文共享作者。
- 稳健性分析排除与任一撤稿论文共享 OpenAlex 作者 ID 的对照。

## 第一级匹配

精确变量：

1. 原论文发表年。
2. OpenAlex 期刊来源。
3. OpenAlex 文献类型。
4. 至少一个 `CN` 机构。
5. `is_retracted = false`。

撤稿年份不作为匹配变量，因为它由后续通知时间决定。

## 第二级学科递进

1. 同 `primary_topic`。
2. 同 `subfield`。
3. 同 `field`。
4. 同 `domain`。

## 退化匹配

期刊年度层不足时：

- 发表年 + 学科 `field` + 出版社。
- 仍不足则保留实际匹配数并标记来源层。
- 不跨年份无限放宽，不使用结果变量选对照。

## 完整性分母

主样本 `0/1/2` 对照完整性按全部中国大陆主分析论文报告。没有可用匹配层和进入匹配层后未获得对照都计入 `0` 篇；可匹配案例内的匹配比例另表报告。

## API 抽样

- OpenAlex 单次 `sample` 实测最多返回 25 条。
- 大层使用多个固定种子批次累计。
- 每个候选对照保存来源层和抽样批次。
- 失败请求不计入未找到。

## 压测证据

25 个期刊年度层、47 篇案例、461 个对照请求成功，返回对照全部确认中国大陆机构。

| 学科层 | 至少 2 个候选 |
|---|---:|
| 同 `primary_topic` | 5/47 |
| 同 `subfield` | 18/47 |
| 同 `field` | 38/47 |
| 同 `domain` | 43/47 |

精确主题匹配过稀，因此必须使用递进规则。
